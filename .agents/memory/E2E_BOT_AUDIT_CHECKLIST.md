# 🐎 ม้าดำ (E2E Bot) - Audit Checklist & Test Results

ไฟล์นี้ใช้สำหรับบันทึกประวัติการรันทดสอบระบบด้วยบอทม้าดำ (End-to-End Testing) เพื่อให้ Agent รับรู้ว่าได้ทำการทดสอบส่วนไหนไปแล้วบ้าง และผลลัพธ์เป็นอย่างไร

## 📋 ประวัติการทดสอบ (Test History)

### 🛒 1. ระบบสั่งซื้อหน้าบ้าน (B2B Frontend Checkout)
*   **สถานะล่าสุด:** `[x] ทดสอบแล้ว (Passed)`
*   **รายการทดสอบ:**
    *   เข้าสู่ระบบ (Login) ด้วยอีเมลลูกค้า
    *   ค้นหาและเพิ่มสินค้าลงตะกร้า (Add to cart)
    *   จัดการตะกร้าสินค้า (Clear cart, สุ่มเลือกสินค้าเพื่อเลี่ยง Buffer)
    *   กรอกที่อยู่จัดส่งและยืนยันบิล
    *   เปิดแถบ "วิธีการชำระเงิน" และแนบสลิป (Slip Upload)
    *   กด Checkout จนได้รับเลขที่ออเดอร์
*   **ผลลัพธ์ / ปัญหาที่พบ:**
    *   พบปัญหาระบบหน่วงเวลาบันทึกตะกร้า (Debounce) ทำให้ตะกร้าว่างเปล่า (แก้โดยให้บอทยืนรอ)
    *   แก้ไขการคลิกผ่าน Cookie Banner และ Accordion จนบอทผ่านฉลุย 100%

### 🏪 2. ระบบหน้าร้าน POS (Backoffice POS Flow)
*   **สถานะล่าสุด:** `[x] ทดสอบแล้ว (Passed)`
*   **รายการทดสอบ:**
    *   เข้าสู่ระบบ (Login) ด้วยบัญชีผู้จัดการ
    *   เข้าเมนูขายหน้าร้าน (POS)
    *   สร้างลูกค้ารายใหม่ (Create New Customer)
    *   ค้นหาลูกค้าที่เพิ่งสร้างและเลือกทำรายการ
    *   เปิดบิลขาย POS
*   **ผลลัพธ์ / ปัญหาที่พบ:**
    *   พบปัญหา Clock Skew (เวลาเครื่องและเซิร์ฟเวอร์เหลื่อมกัน) ทำให้ดึงชื่อลูกค้าที่เพิ่งสร้างไม่เจอ (แก้ไขแล้วโดยเพิ่ม Buffer Time -5 นาที ตอนดึงข้อมูล Delta Sync)
    *   พบปัญหา Firestore Rules ไม่อนุญาตให้พนักงานสร้างลูกค้า (แก้ไขแล้ว)

### ⚙️ 3. ระบบจัดการคำสั่งซื้อ (Order Management)
*   **สถานะล่าสุด:** `[x] ทดสอบแล้ว (Passed)`
*   **รายการทดสอบ:**
    *   แอดมินตรวจสอบออเดอร์ล่าสุดที่เข้ามา
    *   เช็คความถูกต้องของสถานะออเดอร์และข้อมูลลูกค้า
*   **ผลลัพธ์ / ปัญหาที่พบ:**
    *   สถานะออเดอร์และการเชื่อมโยงข้อมูลลูกค้าถูกต้องครบถ้วน

### 📝 4. ระบบจัดการงาน (Todo / Operations Center)
*   **สถานะล่าสุด:** `[x] ทดสอบแล้ว (Passed)`
*   **รายการทดสอบ:**
    *   เข้าสู่ระบบ (Login) ด้วยบัญชีผู้จัดการ
    *   เข้าไปที่เมนูศูนย์ปฏิบัติการ (Todo)
    *   สร้างงานใหม่ (Manual Task) พร้อมระบุข้อมูลจำลอง `(ai สร้าง)`
    *   บันทึกงานและแสดงผลในระบบ
*   **ผลลัพธ์ / ปัญหาที่พบ:**
    *   บอทสามารถกรอกข้อมูลฟอร์ม และบันทึกเข้า Firestore ได้สำเร็จ งานใหม่ปรากฏในรายการอย่างถูกต้อง
