# SSR Memory: Tab Favorites (ห้องทำงานช่าง / สินค้าที่ถูกใจ)

## 1. <usage_workflow>
1. ช่าง/ลูกค้าล็อกอินเข้าสู่หน้าร้าน และเปิดเมนูโปรไฟล์แท็บ "สินค้าที่ถูกใจ" (`/profile?tab=favorites`)
2. ช่างใช้เป็น "ห้องทำงานช่าง": บันทึกโน้ตอาการเสีย, ใส่แท็กหมวดหมู่งาน, จัดลำดับอะไหล่ตามความสำคัญ
3. ช่างสามารถเลือกอะไหล่ทั้งหมดหรือเฉพาะรายการที่ต้องการสั่งซื้อ แล้วกด "ใส่ตะกร้า" เพื่อไปชำระเงินต่อ

## 2. <domain_rules>
- **Sales-First Value Copy:** ข้อความหัวตารางห้องทำงานช่าง ต้องสื่อสารแบบภาษานักขาย บอกความสามารถและจุดขายที่ช่วยช่างทำเงิน/ปิดงานไว ห้ามสอนวิธีใช้งานแบบทื่อๆ
- **Balanced Header Placement:** ข้อความจุดขายถูกย้ายขึ้นไปวางในแถวหัวตาราง (Page Header) อยู่ตรงกลางระหว่างจำนวนรายการและปุ่มสลับมุมมอง (View Mode) ขนาดตัวอักษรเป็น `text-xs` สมดุล ไม่เบียดบังพื้นที่ทำงานด้านล่าง
- **Clean UI & No Box Shapes:** ส่วนข้อความจุดขาย แถบค้นหา, แถบสรุป และกรอบรูปภาพสินค้า (Image Frame) ต้องโปร่ง โล่ง สบายตา ไม่ตีกรอบ (No borders), ไม่ใส่พื้นหลังกล่องทึบ (No container background shape) เพื่อให้ภาพสินค้ากลมกลืนกับการ์ดอย่างเป็นธรรมชาติ
- **Calm UI & Fast Interaction:** ตัวกรองแท็กและเช็คบ็อกซ์เลือกรายการต้องทำงานรวดเร็ว สะอาดตา

## 3. <core_schema>
- **Entry Component:** `Management System/dh-frontend/src/components/profile/tabs/TabFavorites.jsx`
- **Controller Hook:** `Management System/dh-frontend/src/components/profile/tabs/hooks/useFavoriteManagement.js`
- **Data Source / Provider:** `FavoritesProvider.jsx` (จัดเก็บ favorites ใน LocalStorage / IndexedDB / Firestore ตามระดับสมาชิก)
- **Key Fields in Item:**
  - `productId`: ID สินค้า
  - `notes`: โน้ตกำกับงานของช่าง
  - `tag`: แท็กกลุ่มงานซ่อม
  - `order`: ลำดับการแสดงผล

## 5. <pitfalls_and_solutions>
- **ปัญหา 1:** ข้อความเดิมใช้คำว่า *"ห้องทำงานช่าง: สามารถจดบันทึกงาน ใส่แท็ก คัดลอกสรุปราคา และจัดลำดับอะไหล่ขึ้น-ลงได้ทันที"* เป็นการสอนวิธีใช้ ฟอนต์เล็ก (11px) มีกล่องกรอบสีเหลือง แถบค้นหา/แถบเลือกทั้งหมดมีกรอบสีเทาหนา และป้ายแท็ก/โน้ตในการ์ดสินค้ามีกรอบสี่เหลี่ยมพร้อมพื้นหลังสีทึบเกะกะสายตา
- **วิธีแก้ 1:** ถอด container shape, border และ background ทั้งหมดออก (ทั้งแถบค้นหา, แถบเลือกทั้งหมด และป้ายแท็ก/โน้ตใน FavoriteItemCard) ปรับเป็นข้อความและไอคอนโปร่งสะอาดตา ขยายฟอนต์จุดขายเป็น `text-sm sm:text-base` และเปลี่ยนข้อความเป็นภาษานักขาย
- **ปัญหา 2:** ปุ่ม "คัดลอกรายการสรุปราคา" ไม่ต้องการให้มีบนหน้าเว็บ
- **วิธีแก้ 2:** ถอดปุ่มออกจากหน้าจอ `TabFavorites.jsx` และลบโค้ด `handleCopyQuotation`, `copiedQuotation` ออกจาก `useFavoriteManagement.js` อย่างสมบูรณ์ 100%
