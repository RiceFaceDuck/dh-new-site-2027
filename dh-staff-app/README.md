# DH Notebook - Staff App

แอปพลิเคชันสำหรับให้พนักงานระดับปฏิบัติการ (Staff) ใช้งาน เช่น การสแกนสต็อกสินค้า, การจัดการออเดอร์, และการเช็คอิน โดยจะเข้าถึงฟังก์ชันพื้นฐานที่จำเป็นเท่านั้น ไม่อนุญาตให้แก้ไขตั้งค่าระบบหลัก

## 🚀 การติดตั้งและการรันโปรเจกต์

1. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

2. **รัน Local Development Server:**
   ```bash
   npm run dev
   ```

## 📱 แนวทางการพัฒนา (Development Guidelines)

1. **Mobile-First Experience:** Staff App มักถูกเปิดใช้งานบนแท็บเล็ตและโทรศัพท์มือถือ ดังนั้น UI ต้องสามารถปรับตัวเข้ากับหน้าจอขนาดเล็กได้ดี ปุ่มกดต้องมีขนาดใหญ่และกดง่าย
2. **กล้องและการสแกน (Camera / QR):** โปรเจกต์นี้อาจจะมีการใช้กล้องเพื่อสแกนบาร์โค้ดหรือ QR Code (`html5-qrcode` หรือ `react-qr-code`) โปรดทดสอบการขอสิทธิ์เข้าถึงกล้องบนเบราว์เซอร์อย่างระมัดระวัง
3. **การเข้าถึงข้อมูลร่วม (Shared Data):** หากมีการดึงข้อมูลที่เป็นกลาง (เช่น ข้อมูลสินค้าพื้นฐาน) แนะนำให้ใช้ฟังก์ชันจาก `dh-shared`
